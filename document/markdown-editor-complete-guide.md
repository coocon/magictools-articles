## 什么是 Markdown？为什么要学它？

Markdown 是一种轻量级标记语言，由 John Gruber 于 2004 年发明。它的核心理念是：用最少的格式符号，让纯文本具备结构化排版能力，同时保持源文件的可读性。

相比 Word 这类富文本编辑器，Markdown 有以下明显优势：
- **纯文本存储**，不依赖特定软件，任何编辑器都能打开
- **版本控制友好**，和 Git 天然契合，修改历史清晰可见
- **跨平台渲染**，GitHub、Notion、掘金、Hugo 等平台均原生支持
- **专注写作**，不用频繁用鼠标切换格式按钮，思路不被打断

## 基础语法快速上手

### 标题与段落

标题使用 `#` 号，数量对应级别：

```markdown
# 一级标题
## 二级标题
### 三级标题
```

段落之间空一行即可，不需要任何标记。

### 强调与粗体

```markdown
**粗体文字**
*斜体文字*
~~删除线~~
`行内代码`
```

### 列表

无序列表用 `-` 或 `*`，有序列表用数字加点：

```markdown
- 苹果
- 香蕉
- 橙子

1. 第一步
2. 第二步
3. 第三步
```

### 代码块与表格

代码块使用三个反引号，并可指定语言高亮：

````markdown
```python
def hello():
    print("Hello, Markdown!")
```
````

表格语法如下：

```markdown
| 工具名称 | 功能 | 平台 |
|----------|------|------|
| VS Code  | 代码编辑 | 全平台 |
| Notion   | 笔记协作 | 全平台 |
```

## 实时预览的核心优势

MagicTools 的 Markdown 编辑器采用左右分栏设计：**左侧写 Markdown 源码，右侧实时渲染预览**。这种即时反馈机制有几个关键好处：

**消除认知负担**：你不需要在脑海中"翻译"Markdown 符号，写完一段就能立刻看到最终效果，表格对齐是否正确、图片是否加载成功，一目了然。

**降低语法错误率**：忘记闭合代码块的反引号？表格列数不匹配？实时预览会立刻暴露这些问题，无需等到发布才发现排版乱掉。

**加速内容创作**：特别是写技术文档时，代码块和表格的渲染结果立刻可见，减少了反复切换工具预览的时间损耗。

## 多格式导出详解

写好文章后，你可能需要发给不同的人或发布到不同的平台。MagicTools 提供四种导出格式：

### PDF 导出

点击工具栏的「导出 PDF」按钮，浏览器会弹出系统打印对话框。选择「另存为 PDF」即可生成排版精美的 PDF 文件。

**适用场景**：发给客户的报告、需要打印的文档、履历/简历等正式文件。

**小技巧**：在打印设置中关闭「页眉页脚」选项，可以得到更干净的 PDF 版面。

### 图片导出（PNG）

导出 PNG 功能使用 `html2canvas` 技术，将当前渲染的 HTML 截图为高清图片。导出结果是完整的文档截图，适合在社交媒体上分享。

**适用场景**：微信/微博分享技术笔记截图、需要在不支持 Markdown 的平台展示格式化内容。

### HTML 导出

导出的 HTML 文件是独立可运行的网页，包含内联 CSS 样式，无需任何外部依赖，用浏览器直接打开即可。

**适用场景**：发布到静态网站、嵌入到现有网页项目、需要完整保留格式的离线文档。

### Markdown 文件下载

直接下载 `.md` 源文件，保留全部原始 Markdown 格式。

**适用场景**：迁移到其他平台（Hugo、Hexo、Notion）、上传到 GitHub 仓库、版本控制备份。

## 分享链接功能

完成文档后，点击「生成分享链接」，系统会将内容保存到数据库并生成唯一的永久链接，格式为 `tools.cooconsbit.com/share/xxxxx`。

**核心特性：**
- **永久有效**：链接不会过期，可以放心发给任何人
- **匿名分享**：无需登录即可创建分享，保护隐私
- **浏览计数**：可以看到链接被访问了多少次
- **标题编辑**：登录用户可以在 Dashboard 中修改分享标题，方便管理多个分享

**实用场景**：给同事分享技术方案草稿、在论坛回复中附上格式化代码文档、临时展示设计规范。

## 常见问题 FAQ

**Q：如何把 Markdown 文档转换为 Word 格式？**

A：直接导出 Word 需要借助第三方工具。推荐的方式是：先从 MagicTools 导出 HTML 文件，然后用浏览器打开 HTML，全选后复制粘贴到 Word 中，格式基本能保留。或者使用命令行工具 Pandoc：`pandoc input.md -o output.docx`，效果更专业。

**Q：Markdown 和 Word 这类富文本编辑器哪个更好？**

A：两者各有适用场景。Markdown 更适合技术文档、博客文章、README、需要版本控制的内容；Word 更适合需要精确排版的正式文件（合同、报告）以及需要多人实时协作编辑的场景。如果你经常写技术内容，建议切换到 Markdown，长期来看效率提升明显。

**Q：MagicTools 的 Markdown 编辑器支持哪些平台？**

A：完全基于浏览器，支持所有现代浏览器（Chrome、Firefox、Safari、Edge），无需安装任何插件或客户端。在手机浏览器上也可以正常使用，但建议在桌面端操作以获得最佳体验。

**Q：分享链接生成后内容还能修改吗？**

A：分享链接对应的内容在生成后会存储在服务器，内容本身不可修改（保证链接内容的一致性）。但登录用户可以在 Dashboard 中修改分享的**标题**，并可以删除不需要的分享记录。

**Q：编辑器支持数学公式渲染吗？**

A：当前版本暂不支持 LaTeX 数学公式渲染。对于需要展示数学内容的场景，可以使用截图（从其他支持公式的工具截图后上传图床）作为替代方案。
