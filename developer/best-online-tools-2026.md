## 选工具的三条原则

在进入清单之前，先说三条筛选原则，这也是你自己评估工具时的参考标准：

1. **免费优先**：核心功能免费可用，不要被"免费试用 14 天"骗进去
2. **隐私友好**：敏感数据（代码、密钥、文档）尽量选择本地处理或开源工具，不轻易上传到陌生服务器
3. **无需注册**：立即可用的工具比"注册后体验完整功能"的工具效率高 10 倍

## 一、文档与写作

好文档是工程质量的一部分。这类工具帮你更高效地写 README、API 文档、技术博客。

**[MagicTools Markdown 编辑器](https://tools.cooconsbit.com/tools/markdown)**
实时分栏预览，支持 GFM 语法，内容可一键生成分享链接，适合临时协作和内容展示。导出支持 PDF、HTML、图片多种格式。

**[HackMD](https://hackmd.io)**
团队协作 Markdown，支持多人实时编辑、版本历史、自定义域名发布。适合技术团队的共享笔记和会议记录。

**[readme.so](https://readme.so)**
拖拽式 README 生成器。提供安装说明、使用示例、贡献指南、许可证等常用区块，拖拽组合后一键导出 Markdown。为开源项目写 README 时节省 80% 时间。

**[Markmap](https://markmap.js.org/repl)**
把 Markdown 文档实时转换成思维导图。适合整理架构设计思路，或把复杂文档可视化呈现。

## 二、格式转换

开发者每天要处理各种数据格式，这类工具是日常必备。

**[MagicTools HTML 转 Markdown](https://tools.cooconsbit.com/tools/html2md)**
支持粘贴 HTML 代码、输入 URL 抓取、粘贴富文本三种输入方式，输出干净的 Markdown，适合从网页提取内容迁移到文档系统。

**[JSON Formatter & Validator](https://jsonformatter.curiousconcept.com)**
JSON 格式化、校验、压缩一站搞定。支持检测 JSON 语法错误并精确定位到行号，调试 API 响应必备。

**[Base64 Guru](https://base64.guru)**
Base64 编解码，支持文本和文件（图片直接转 Base64 字符串，用于 CSS 内联图片或邮件模板）。

**[URL Decode Encode](https://www.urldecoder.org)**
URL 编解码，处理包含中文或特殊字符的 URL 参数时不可少，同时支持批量处理。

**[Transform.tools](https://transform.tools)**
一站式代码格式转换神器，支持：JSON → TypeScript 类型、JSON → Go Struct、SVG → React 组件、CSS → Tailwind 等数十种转换，开发者日常高频使用。
