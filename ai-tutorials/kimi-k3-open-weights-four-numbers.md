# Kimi K3 开权重前夜：四个被广泛误读的数字

> 📍 本文首发于 [MagicTools 码农早餐](https://tools.cooconsbit.com/zh/articles/kimi-k3-open-weights-four-numbers?utm_source=github&utm_medium=referral)。镜像仓库仅收录预览，**[点此阅读全文 →](https://tools.cooconsbit.com/zh/articles/kimi-k3-open-weights-four-numbers?utm_source=github&utm_medium=referral)**

月之暗面承诺的 Kimi K3 完整权重发布时间是 2026 年 7 月 27 日 00:00 UTC。我写这段话的时候距离那个时间点还有几个小时。

在等待的这几个小时里，关于 K3 的四个数字已经在中英文互联网上跑了一圈半：**2.8 万亿参数**、**51% 幻觉率**、**六项榜单第一**、**3.3 万亿美元市值蒸发**。

这四个数字都是真的。四个数字最流行的那种解读，都是错的。

它们错得还很有规律——每一次都是把**模型的数字**，直接当成了**系统的结论**。这篇文章把四个分母逐个拆开。

## 数字一：2.8 万亿参数 —— 「开源了，我终于能本地跑了」

这是传播量最大、也最快会被现实教育的一条。

先说 K3 是什么。2.8 万亿总参数的稀疏 MoE，896 个专家每 token 只激活约 16 个，所以单 token 的计算量远低于同规模稠密模型；100 万 token 上下文；原生视觉理解；架构上有两项新东西——KDA（Kimi Delta Attention，线性注意力与标准二次注意力的混合）和 Attention Residuals，据称在百万 token 长度上解码快到 6.3 倍。训练用了 MXFP4 权重 + MXFP8 激活的量化感知训练，所以放出来的是**原生 4bit 权重**，不是事后压的。

问题出在「本地跑」这三个字上。

按公开信息，光是把权重装进显存就需要 **1.5TB 以上的 HBM**，月之暗面自己建议的服务配置是**至少 64 张加速卡的超节点集群**。一张 RTX 4090 跑不了，一台 Mac Studio 跑不了，8 张 H100 是**下限**而不是舒适区。

这里还有一个值得注意的算术不一致：多方报道给出的下载体积是约 **594GB**，但 2.8 万亿参数按 4bit 存储应该是约 **1.4TB**。两个数字对不上。可能的解释是分片压缩、部分层用了更低精度、或者某处报道有误——**发布后请以仓库里的实际文件体积为准**，别拿转述数字做容量规划。

真正的结论不是「K3 太大了」，而是：**「开源权重」和「个人开发者能用」这两件事，在 K3 这里第一次被彻底解耦了。**

以前开源模型的意义链条是完整的：权重公开 → 我下载 → 我在自己机器上跑 → 我不再依赖任何厂商。K3 把中间两环打断了。权重确实公开，但能消费这份公开的，是有多节点 GPU 集群的机构：云厂商、大公司平台团队、有预算的研究机构。个人开发者拿到的，最终还是一个 API 端点。

「开源」这个词的**政治含义**没变——可审计、可自托管、不被单一厂商卡脖子。但它的**实用含义**变了：对绝大多数人来说，K3 开源意味着「更多厂商会以更低的价格提供 K3 API」，而不是「我可以自己跑」。

这不是坏事，只是和大家默认的那个故事不一样。

## 数字二：51% 幻觉率 —— 「一半的话都是编的」

这条误读最严重，因为它的分母被换掉了。

来源是 Artificial Analysis 的 AA-Omniscience 基准测试。真实数据是：相比前代 K2.6，K3 的**准确率从 33% 升到 46%**，同时**幻觉率从 39% 升到 51%**。

关键在于 AA-Omniscience 的幻觉率定义：**错误回答 ÷ 所有非正确回答**，而不是「错误回答 ÷ 全部回答」。也就是说，51% 描述的是——在模型**没答对**的那些题里，它有一半是**编了一个答案**，另一半是**承认自己不知道**。

有个对照能立刻校准直觉：**Claude Fable 5 在同一榜单上是 54.9%**，比 K3 还高。所以「51%」这个绝对值本身根本不构成 K3 的独有问题。有媒体把它写成「模型说的话大约一半是错的」——那是把分母从「非正确回答」偷换成了「全部断言」，量级完全不同。

那这条数据到底有没有价值？有，但价值在**轨迹**而不是**水位**：

> 模型同时变得更会答题（33% → 46%），和更不会说「我不知道」（39% → 51%）。

这是一个具体的、可讨论的工程取舍：在优化基准分数的过程中，弃权（abstention）行为被牺牲掉了一部分。而 AA-Omniscience 的综合 Index 分数还是从 +6 涨到了 +18，因为它的打分公式里准确率的权重压过了幻觉惩罚。
