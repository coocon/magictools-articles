## IP 地址基础知识

在深入了解工具功能之前，有必要先理清几个容易混淆的概念。

### IPv4 vs IPv6

**IPv4**（Internet Protocol version 4）是目前使用最广泛的 IP 协议版本，地址由 4 组 0~255 的数字组成，用点分隔，如 `192.168.1.1`。IPv4 地址空间约为 42 亿个，随着互联网爆炸式增长，地址已接近耗尽。

**IPv6**（Internet Protocol version 6）是下一代 IP 协议，地址由 8 组十六进制数字组成，用冒号分隔，如 `2001:0db8:85a3:0000:0000:8a2e:0370:7334`。IPv6 的地址空间几乎无限（约 3.4 × 10^38 个地址），可以为地球上每一粒沙子分配一个 IP 地址。

目前大多数网络同时支持 IPv4 和 IPv6（双栈），你的设备可能同时拥有两种格式的 IP 地址。

### 公网 IP vs 内网 IP

**公网 IP**（Public IP）是互联网上可以被其他设备直接访问的 IP 地址，由你的网络运营商（ISP）分配。一个家庭或办公室通常共享一个公网 IP。

**内网 IP**（Private IP）是局域网内部使用的 IP 地址，仅在局域网范围内有效，不能被外网直接访问。常见的内网地址段：
- `10.0.0.0` ~ `10.255.255.255`
- `172.16.0.0` ~ `172.31.255.255`
- `192.168.0.0` ~ `192.168.255.255`

在 Windows 上运行 `ipconfig`，在 Mac/Linux 上运行 `ifconfig` 或 `ip addr`，看到的 IP 地址通常是内网 IP。而通过 IP 查询工具看到的，才是你的真实公网 IP。

显示的信息通常包括：

## 网络诊断应用场景

IP 查询工具的价值不只是「查一下 IP 地址」，它在实际的网络诊断和日常使用中有多个重要场景。

### 场景一：VPN 连接验证

使用 VPN 时，你需要确认流量是否真的通过了 VPN 服务器转发。方法很简单：

1. **连接 VPN 前**：打开 IP 查询工具，记录当前 IP（如 `221.176.xx.xx`，中国电信北京）
2. **连接 VPN 后**：刷新 IP 查询页面，查看 IP 是否变化
3. **验证结果**：如果 IP 变成了 VPN 服务器所在地（如 `104.21.xx.xx`，美国 Cloudflare），说明 VPN 生效；如果 IP 没变，说明存在 VPN 泄露问题（DNS leak 或 WebRTC leak）

这是验证 VPN 效果最直观、最可靠的方法，比相信 VPN 客户端的「已连接」状态要可靠得多。

### 场景二：服务器问题排查

运维工程师经常遇到「网站在某些地区访问慢或无法访问」的报告。IP 查询工具可以帮助快速定位问题：

- 查询服务器 IP 的地理位置是否与预期一致（CDN 配置正确吗？）
- 检查服务器 IP 是否属于被某些运营商屏蔽的网段
- 对比不同 IP 的 ASN 信息，判断是否是路由层面的问题

### 场景三：内容访问限制检测

某些平台（流媒体、SaaS 工具）会根据 IP 地理位置限制访问。当你发现某个服务无法使用时，先查询当前 IP 显示的地理位置，确认是否与服务的访问限制有关。

例如：你明明在香港，但 IP 查询显示你的 IP 归属地是中国大陆，可能是因为你使用了某个路由策略导致流量绕道。

### 场景四：开发调试

开发需要根据用户 IP 显示不同内容的功能（如地区定价、本地化内容）时，可以使用 IP 查询工具快速验证 IP 地理数据库的解析结果是否正确，以及你的开发环境的 IP 是否会影响测试结果。

MagicTools 的 IP 查询功能完全在前端完成（通过调用公开的 IP 数据库 API），服务器**不存储**你查询的 IP 地址或查询历史。每次查询都是独立的一次性请求，不会与你的账号关联，也不会留下可追踪的记录。

## 常见问题 FAQ

**Q：我的 IP 地址安全吗？会泄露隐私吗？**

A：IP 地址本身并不等同于个人隐私泄露。公网 IP 是网络通信的必要标识，你访问的任何网站都会记录你的 IP。IP 地址能暴露的信息仅限于：你的大致地理位置（城市级别）和你使用的运营商。要精确定位到你的家庭住址，仅凭 IP 是做不到的，需要配合运营商的用户数据（且通常只有执法机构才能申请调取）。真正需要担心的隐私风险是账号信息泄露、Cookies 追踪等，而不是 IP 本身。

**Q：如何隐藏我的真实 IP 地址？**

A：主要有三种方式：①**VPN（虚拟私人网络）**：流量通过 VPN 服务器中转，网站看到的是 VPN 服务器的 IP，而不是你的真实 IP。②**代理服务器**：原理类似 VPN，但通常只针对特定应用的流量。③**Tor 网络**：流量经过多重加密和中转节点，匿名性最高，但速度较慢。对于日常隐私保护需求，可靠的商业 VPN 是最实用的选择。

**Q：IPv4 和 IPv6 有什么实际区别？我需要关心哪个？**

A：对于普通用户，日常使用基本感觉不到区别。主要差异在于地址格式（IPv4 是点分十进制，IPv6 是冒号分十六进制）和地址数量（IPv6 几乎无限）。如果你查询时同时显示了 IPv4 和 IPv6 地址，说明你的网络已启用双栈。在应用场景上：网络游戏有时对 IPv4/IPv6 有偏好；某些 ISP 的 IPv6 网络质量可能与 IPv4 有差异。如果没有特别需求，通常让系统自动选择即可。

**Q：为什么 IP 查询显示的城市位置和我实际位置不符？**

A：IP 地理位置数据库（GeoIP）的城市级精度通常在 50~200 公里范围内，对于固定宽带用户来说，可能显示为 ISP 骨干节点所在城市，而非你实际所在城市。这是正常现象，IP 定位本身只能提供粗略的地理参考，不能作为精确位置的依据。

**Q：公司网络和家庭网络的 IP 有什么不同？**

A：公司通常使用固定公网 IP（Static IP），即 IP 地址固定不变，适合运行服务器、设置访问白名单。家庭宽带通常使用动态 IP（Dynamic IP），每次拨号或路由器重启后 IP 可能发生变化（同一运营商分配的 IP 段通常相对稳定，但不绝对）。如果你需要固定 IP，可向运营商申请固定 IP 服务（通常需额外付费）。
